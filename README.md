The one line a gamer texts the boss to skip work on GTA 6 launch week, written for make.fun's "The Excuse That Almost Works" bounty.

## The excuse

> My kitchen tap is leaking into the flat below and the plumber can only come between nine and five.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this excuse

It is boring, specific and true-shaped: a leak, a downstairs neighbour, and a tradesman whose only window is exactly the working day. A tired manager has heard every excuse twice, but this one has a real detail that checks out — the plumber's hours are the boss's hours, which is the joke hiding inside the excuse itself. No dead grandmother, no flat tyre, no sudden fever: just plumbing, and a window the manager cannot argue with because the plumber set it. It reads like a text sent in a hurry, plain words, no setup, no explanation, no signature. One line, 98 characters and 19 words, inside the 140-character and 20-word gates.
